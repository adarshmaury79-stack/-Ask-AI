🔑 API key

Add your own free Gemini API key for unlimited chatting (within Google's free limits). Get one (no card needed) at aistudio.google.com/apikey and paste it below.

How to get a free Gemini API key
  1. Open aistudio.google.com/apikey in Chrome and sign in with your Google account.
  2. Tap Create API key.
  3. Choose Create API key in new project (the project name can be anything).
  4. Your key will appear (it starts with AIza). Tap Copy.
  5. Come back here, paste it in the box below and tap Save.
  6. Now ask your question again. Keep your key private and never share it with anyone.
Your key is saved only in this browser. Leave empty and Save to remove it.
